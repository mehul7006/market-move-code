Segments — click any card for its individual signal

Educational research tool — not investment advice. Every number on this desk comes from the live Upstox feed (or Yahoo real candles as a labelled fallback) — there is no mock mode. If a feed fails you will see a red error, never invented data. Calls are issued only for Sensex, Nifty, Bank Nifty, Fin Nifty, Midcap Select and Next 50; sector indices are chart context only. Each segment runs its own six-month tested profile (session-bounded at 15:25 IST, unanimous indicators, wide stop) and may call only while its measured T1-before-stop rate is ≥75%. Those are in-sample base rates, not a forward guarantee: the wide stop puts R:R near 0.25–0.4, so break-even is roughly 71–80% before costs. The Nifty 50 stock book repeats that test on every constituent's own bars (T1 = 0.6×ATR, stop = 3.4×T1) and issues a stock call only while its own rate clears 75% over ≥100 setups; breadth there is an equal-weight count of advancers/decliners, not the index's free-float move. Derivatives and single stocks carry substantial risk of loss.

Access — Upstox token & public link

Paste a fresh Upstox access token, or the full address you were redirected to after logging in. It is checked with Upstox first, then saved to the gitignored .env and applied to the running server — no restart, no code edit.

Two tokens: paste the daily token as usual, and (once) Upstox's 1-year Analytics token — it is stored as an automatic fallback and takes over whenever the daily token expires. Why it asks again: an Upstox access token is valid only until about 03:30 IST the next morning. On Render's free plan the disk is wiped whenever the service sleeps, so a token pasted here is forgotten. Put the token in the Render environment variable UPSTOX_ACCESS_TOKEN (it survives restarts), or use Upstox's 1-year read-only Analytics token.
